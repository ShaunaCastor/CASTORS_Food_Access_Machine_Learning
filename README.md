CASTORS_Food_Access_Machine_Learning

Applied machine learning and geospatial research examining food-access patterns in Trumbull County, Ohio using Decision Tree and Random Forest models, GIS data integration, and model evaluation.

Project Status: Ongoing Research | 2026

Overview
The CASTORS Research Initiative explores how artificial intelligence, geospatial analytics, and publicly available data can be used to investigate food-access patterns and socioeconomic disparities.
The initial research focuses on Trumbull County, Ohio, with particular attention to Warren, Ohio.
Using AI-assisted coding, I developed and evaluated Decision Tree and Random Forest machine learning models to investigate relationships between socioeconomic conditions, transportation access, geographic characteristics, and food assistance participation.
The project demonstrates an approach to AI capability development in which the researcher defines the problem, establishes analytical requirements, directs model development, evaluates results, and determines opportunities for refinement.
The central question extends beyond whether a model can be built: How do we determine whether an AI-enabled analytical capability works, can be trusted, and is useful for its intended purpose?

AI-Assisted Coding Methodology
This project was developed using AI-assisted coding rather than exclusively manual software development.
Generative AI tools supported the creation, refinement, and troubleshooting of Python scripts used for data preparation, machine learning, and model evaluation.

I guided the analytical process by defining research objectives, specifying modeling requirements, executing code, reviewing outputs, troubleshooting implementation issues, and interpreting results.
This approach enabled the development and testing of analytical capabilities while maintaining a focus on research design, model evaluation, and responsible application.
AI-generated code and analytical outputs were treated as materials requiring review and testing, rather than as automatically validated results.

Research Question
Can Decision Tree and Random Forest models identify meaningful patterns associated with food assistance participation, and how reliable are those models for understanding community-level food-access conditions?
Research Objectives
1.	Integrate publicly available demographic, economic, transportation, and geographic datasets.
2.	Examine relationships between selected socioeconomic indicators and food assistance participation.
3.	Develop Decision Tree and Random Forest models using AI-assisted Python coding.
4.	Evaluate and compare model performance using quantitative validation methods.
5.	Identify limitations related to data quality, model interpretation, and generalizability.
6.	Communicate research findings through geographic visualization and explanatory data stories.

Data Sources and Geospatial Integration
The research incorporates publicly available datasets from sources including:

•	U.S. Census Bureau: American Community Survey socioeconomic and demographic indicators.
•	U.S. Department of Agriculture: SNAP retailer access and related food-access information.
•	U.S. Environmental Protection Agency: Excess food opportunity datasets.
•	USDA Agricultural Marketing Service: Local agricultural and food market information.

Using ArcGIS, I integrated geographic and socioeconomic information through data preparation, geographic identifier matching, spatial joins, proximity analysis, and buffer analysis.
These processes supported the creation of a consolidated analytical dataset for machine learning.

Machine Learning Capability Development
Decision Tree Model
Using AI-assisted Python coding, I developed a Decision Tree model to examine relationships between selected socioeconomic and geographic predictors and the research outcome.
The Decision Tree approach was selected in part for its interpretability and ability to illustrate how predictors contribute to model estimates.
Random Forest Model
I subsequently developed a Random Forest model using AI-assisted coding to examine whether an ensemble approach could improve predictive performance.
The Random Forest model provided an opportunity to compare alternative analytical approaches and investigate relationships among the selected variables.

Model Evaluation
The models were tested using evaluation methods that included:
•	Cross-validation
•	Mean Absolute Error (MAE)
•	Root Mean Squared Error (RMSE)
•	R-squared (R²)
•	Comparative performance analysis

These evaluations were used to examine predictive performance, identify limitations, and guide decisions about future model refinement.
The research emphasizes that producing a prediction is not equivalent to demonstrating that a model is sufficiently reliable for real-world use.
Responsible AI and Model Reliability
The initiative incorporates several principles relevant to responsible AI capability development.
Data Quality and Suitability: Assessing whether available datasets adequately represent the research problem.
Model Evaluation: Testing predictive performance and comparing alternative approaches.
Interpretability: Examining how selected variables relate to model estimates.
Bias and Generalizability: Considering how data coverage, geographic aggregation, and variable selection may influence results.
Human Oversight: Reviewing AI-assisted code and analytical outputs rather than accepting them without examination.
Operational Usefulness: Evaluating whether model findings are sufficiently meaningful and reliable to inform further research or community discussions.
The models are exploratory research tools. They are not intended to determine individual eligibility for food assistance or make automated decisions about individuals.

Broader Significance
The growing accessibility of AI-assisted development tools creates opportunities for researchers, policy professionals, and technical leaders to participate more directly in building and evaluating analytical capabilities.
However, the ability to generate working code does not eliminate the need for rigorous testing, subject-matter expertise, human oversight, and sound methodological judgment.
The CASTORS Research Initiative explores this intersection by combining AI-assisted coding, machine learning, geospatial research, and model evaluation.
The objective is not simply to build models. It is to understand how analytical capabilities should be designed, tested, evaluated, and improved before their findings are used to inform decisions.
